# _devtest — проверка приложения в настоящем браузере

Этот каталог **не часть приложения** (он не подключается из `index.html`).
Здесь лежит только автоматическая проверка: она поднимает локальный
HTTP-сервер, запускает Edge в headless-режиме, загружает фото и прогоняет
34 проверки — загрузка фото, авто-переход в редактор, размеры раскладки,
пресеты, undo/redo, маски, рамки, окно кадрирования, экспорт.

## Запуск

```powershell
# Node из окружения DSH (обычный node тоже подойдёт)
& "C:\Users\swart\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\node\bin\node.exe" _devtest\suite.js
```

Если запускаете из-под песочницы DSH, headless-браузеру нужен доступ к своим
IPC-каналам — команду придётся выполнить с полным доступом к процессам
(`danger-full-access`), иначе Edge падает на старте с `Access is denied`.

Проверка печатает `PASS`/`FAIL` по каждому пункту и завершается кодом 1,
если что-то упало. Скриншоты не сохраняются.

## Что внутри

- `suite.js` — сам прогон (все проверки сразу, включая чистоту консоли:
  любая необработанная ошибка или `console.error` в странице валит прогон).
- `mobile-check.js` — мобильные проверки: все вкладки нижней панели целиком
  влезают в экран (без горизонтальной прокрутки), убранной вкладки
  «Настройки» нет, а узлы мастер-кривой реально двигаются пальцем
  (события посылаются как `pointerType: 'touch'` — обычный
  `Input.dispatchTouchEvent` до pointer-обработчиков не доходит и такую
  проверку не проверит).
  Запуск: `node _devtest/mobile-check.js 390 844` (ширина высота).
- `layout-check.js` — быстрый замер геометрии редактора на заданном размере
  экрана: `node _devtest/layout-check.js 412 915` (телефон), `1440 900`
  (десктоп), `844 390` (телефон в ландшафте). Печатает размеры ключевых
  блоков и сохраняет скриншот.
- `test-photo.jpg` — тестовое фото 1600×1067 (градиент, яркие блики для
  halation/bloom, тёмная зона и мелкая текстура для зерна).
