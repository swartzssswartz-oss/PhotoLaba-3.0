# СВЕМА ЛАБ — фирменный стиль и интерфейс

Логотип перерисован векторно по мотивам исходного знака: конструктивистская
геометрия, чистый синий, много воздуха. Палитра снята пипеткой прямо с исходной
картинки — синий `#0A4AA8`, чёрный `#141414`, бумага `#E5E3DD`.

Интерфейс приложения переведён на ту же систему: чёрный холст (по нему удобнее
оценивать кадр), плоские панели, много белого и один синий акцент. Никакого
стекла, блюра и градиентов — только массы, линии и воздух, в духе Ле Корбюзье.

## Система коротко

- **Чёрное — основа, белое — графика.** Действия и активные состояния решены
  белыми плашками с чёрным текстом (как знак работает в печати), а не цветом.
- **Правило цвета 60 / 30 / 10** — чёрное поле, белая конструкция, синяя метка.
  Синий — самый редкий гость: он остался только меткой выбора.
- **Модуль** — знак построен на сетке с шагом 1: колонна ровно 2 модуля из 18,
  горизонталь 14,6 × 1,96, круг R 3,24 с центром (9,5; 8,92). Круг касается
  горизонтали ровно в одной точке.
- **Охранное поле** — 0,3 высоты знака. Минимум 14 мм в печати, 48 px в цифре.
- **Шрифты** — системные: Arial Black для заголовков и логотипа, Segoe UI для
  текста, Consolas для значений и технических подписей. Ничего покупать не нужно.
- **Градиентов нет.** Красный, зелёный и жёлтый появляются только там, где несут
  смысл: каналы R/G/B и три статуса.

## Интерфейс приложения

Все токены живут в `assets/styles/base.css` (блок `:root`) — остальные файлы
стилей ссылаются только на них:

| Токен | Значение | Где |
|---|---|---|
| `--bg` | `#000000` | холст, шапка, статус-строка |
| `--panel` / `--panel-2` / `--panel-3` | `#0B0B0B` / `#141414` / `#1C1C1C` | сайдбары, блоки панелей, поля |
| `--line` / `--line-strong` / `--line-bright` | `#2E2E2E` / `#4E4E4E` / `#787878` | разделители и рамки; заметно светлее прежнего |
| `--line-tint` / `--line-tint-strong` | белый 8 % и 22 % | рамки кнопок в покое, подсветка при наведении |
| `--text` / `--text-soft` / `--text-muted` / `--text-dim` | `#FFFFFF` / `#E8E8E6` / `#9CA1A8` / `#6E7378` | четыре уровня текста |
| `--active-bg` / `--active-fg` | `#FFFFFF` / `#0A0A0A` | **активная кнопка, вкладка, плёнка** |
| `--accent` / `--accent-hover` / `--accent-press` | `#1557C8` / `#1E63DC` / `#0A4AA8` | метка выбора и график кривой |
| `--radius-sm` / `--radius-md` / `--radius-lg` | `2` / `4` / `6` px | строгая геометрия вместо «пилюль» |
| `--ok` / `--warn` / `--danger` | `#4FA46A` / `#C9A227` / `#C0473C` | только статусы |

Что изменилось по существу:

- холст кадра — чистый `#000000` без рамки, скруглений и тени: подложка не должна
  влиять на восприятие тонов;
- стекло (blur, полупрозрачные градиенты, объёмные тени) убрано полностью —
  панели плоские, разделены линиями в 1 px;
- **активные состояния переделаны:** раньше это были синие плашки, теперь — белые
  с чёрным текстом. Синий остался тонкой меткой: линия слева у активной плёнки,
  подчёркивание активной вкладки, график кривой;
- белого стало заметно больше: светлее границы и разделители, белый торец по
  верхнему краю шапки, белая метка у заголовка каждого блока настроек, белые
  подписи значений и статус-строки;
- бегунок слайдера стал квадратным (14 px), трек — линией 2 px с синей заливкой
  до текущего значения: измерительный инструмент вместо «капли»;
- шрифты приведены к бренду: Segoe UI для интерфейса, Consolas для значений;
- иконки приложения (`assets/icons/`) перерисованы: чёрное поле, знак, синий круг.

## Нотка Ле Корбюзье: пять приёмов

Внесены не как орнамент, а как конструкция — каждый приём что-то держит,
разделяет или измеряет (страница 19 брендбука):

1. **Столбы-опоры (pilotis).** Белые волосяные линии несут композицию: рамки
   кнопок, белая метка у заголовка блока, разделители, белый торец шапки.
   Декора нет — есть несущее.
2. **Свободный план (plan libre).** Раскладка асимметрична: список плёнок 176 px,
   параметры 236 px, центр отдан кадру. Ровные доли дают вялость, асимметрия —
   направление.
3. **Брис-солей (brise-soleil).** Ламели вместо глухой стены: вертикальные белые
   линии между вкладками и сегментами отделяют зоны, но не закрашивают их.
4. **Сад на крыше (toit-jardin).** Белое поле вверху каждого блока и воздух вокруг
   кадра — пауза в ритме. Пустое место здесь так же важно, как залитое.
5. **Модулор (le Modulor).** Пропорция как инструмент: под дорожкой слайдера идёт
   шкала с делениями, крайние — белые. Значение читается на глаз, без числа.

Плюс «глубокий проём» Роншана: у каждого блока светлая верхняя кромка и тёмная
нижняя — объём двумя линиями, без градиентов и блюра.

В разметке это три маленьких класса: `.modulor` (шкала делений под слайдером),
`.modulor-scale` (пределы диапазона моноширинным) и `.tab-item + .tab-item`
(ламель между сегментами). Остальное — свойства уже существующих блоков.

## Сайт (лендинг)

Сайт — тот же `index.html`: стартовый экран и редактор в одном файле, работает
с `file://` без сервера. Лендинг собран по тем же приёмам (страница 20 брендбука):

- **знак-опора** — вместо пульсирующей точки в шапке теперь модуль логотипа:
  синяя плашка, белая перекладина, визир. Тот же рисунок в шапке редактора (SVG)
  и в иконке приложения;
- **кадр-масса** — зона загрузки стала чертёжной рамкой с угловыми засечками
  вместо пунктирного «окошка»; пунктир в системе остался только служебным;
- **брис-солей** — три модуля движка (Film Response, Grain Engine, Halation)
  делят одну рамку вертикальными ламелями, а не висят отдельными карточками;
- **модулор** — в подвале линейка с 12 делениями: ритм экрана и место для версии;
- **сад на крыше** — воздух сверху (`clamp(24px, 7vh, 72px)`) и широкая колонка
  900 px: масса «плавает», а не прилипает к краям.

Заголовок подписан по-русски — «СВЕМА ЛАБ» и дескриптор «Фото · Видео ·
Эксперименты», как в брендбуке. Ссылки в подвале — те же, что были.

Важно: связка с кодом сохранена. JS обращается к `#landingPage`, `#dropZone`,
`#fileUploader` и создаёт остальные элементы в рантайме — я проверил: ни одного
потерянного id или класса без стилей.

Прежние стили сохранены в `assets/styles-backup-20261007-1309/` — если что-то
понадобится откатить, достаточно вернуть файлы оттуда.

## Как пересобрать

Всё собирается из исходников в `build/` (нужен только Python со стандартной
библиотекой — сторонних пакетов нет):

```powershell
$py = "C:\Users\swart\.dsh\dsh-runtimes\dsh-primary-runtime\dependencies\python\python.exe"
& $py build\brandbook.py "СВЕМА-ЛАБ-брендбук.pdf"   # PDF: 16 страниц A4 + 2 макета интерфейса
& $py build\make_svg.py                             # векторные SVG-ассеты логотипа
& $py build\make_icons.py                           # иконки приложения (PNG + icon.svg)
& $py build\contact.py "СВЕМА-ЛАБ-брендбук.pdf" preview 62 2   # PNG-превью
```

Состав `build/`:

- `pdfwriter.py` — сборка PDF: встраивание TrueType-шрифтов (Type3), контуры
  глифов, кириллица, сжатые потоки. Написан свой, потому что в этом окружении
  недоступны ни headless-браузер, ни установка reportlab;
- `engine.py` — движок вёрстки: палитра, типографика, сетка 12 колонок, отрисовка
  знака и сцепки из одной модели (PDF и SVG совпадают); поддерживает страницы
  произвольного формата — на них сделаны макеты интерфейса;
- `brandbook.py` — 16 страниц документа;
- `interface_pages.py` — 2 страницы-макета интерфейса (экран редактора; мобильный
  экран, обрезка, экспорт) в тех же токенах, что и `base.css`;
- `make_icons.py` — иконки приложения из той же геометрии знака;
- `make_svg.py` — экспорт логотипа в SVG из той же геометрии;
- `pdfraster.py` — собственный растеризатор PDF (для визуальной проверки макета);
- `restyle_modules.py` — разовый скрипт перевода `modules.css` на фирменные токены
  (оставлен как история правки);
- `lc_reference.py` — страница-словарь «пять приёмов Ле Корбюзье → интерфейс»;
- `contact.py`, `preview.py` — превью в PNG.

Текст в PDF векторный и выделяемый, шрифты встроены — файл можно отдавать
в типографию или открывать на любом устройстве.
