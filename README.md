# СВЕМА LAB :: Film Simulation Engine


## Установка как приложение (PWA)
Баннер "Установить СВЕМА LAB" появляется внизу экрана автоматически.

**Важно:** это работает только если сайт открыт по **HTTPS** или на **localhost**.
Браузеры сознательно блокируют Service Worker (а без него не будет и промпта
установки) на обычном `file://` — то есть если вы просто дважды кликнули по
`index.html`, баннер либо не появится, либо появится, но кнопка "Установить"
не сработает.

Чтобы проверить локально — поднимите любой локальный сервер в папке проекта:

```bash
# Python (уже есть почти везде)
python3 -m http.server 8080
# затем открыть http://localhost:8080

# или Node, без установки
npx serve .
```

Для реального использования на телефоне — залейте папку на любой хостинг с
HTTPS: GitHub Pages, Netlify, Vercel, Cloudflare Pages — все бесплатные и
дают HTTPS из коробки.

На **iOS Safari** нативного промпта не бывает в принципе (Apple не
поддерживает `beforeinstallprompt`) — там баннер покажет инструкцию
"Поделиться → На экран «Домой»" вручную.

## Производительность на мобильных
Пока вы тащите слайдер, движок считает превью на уменьшенном буфере
(420px по длинной стороне) — быстро, без подвисаний. Через ~140мс после
отпускания автоматически досчитывается полное качество. Экспорт (кнопка
"Экспорт") всегда идёт в полном разрешении независимо от этого режима.

## Структура
```
index.html
sw.js                      — Service Worker (кеш + офлайн)
assets/
  app.js                   — UI-слой
  pwa.js                   — логика промпта установки
  manifest.json            — Web App Manifest
  data/film-data.js        — база плёнок + схема состояния
  engine/                  — модульный движок симуляции (9 модулей)
  styles/                  — CSS
  icons/                   — иконки приложения
```
